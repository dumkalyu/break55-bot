# Бот Пробой55

Telegram-бот пробойной системы для акций S&P 500, которые торгуются на Bybit.
Работает на серверах GitHub бесплатно, компьютер можно выключать.

- **Итоги дня** приходят со вторника по субботу около 01:30 мск (GitHub иногда опаздывает на 10–60 минут).
- **Кнопки** (🔎 Анализ, 📋 Позиции, 🧭 Рынок, ❓ Помощь) проверяются раз в 30 минут, поэтому ответ приходит не сразу.
- Состояние (что куплено) хранится в `bot_state.json`, учебный журнал сделок — в `paper_journal.csv`.

Ручной запуск: вкладка **Actions** → «Итоги дня» или «Кнопки» → **Run workflow**.

Секреты (Settings → Secrets and variables → Actions): `TELEGRAM_TOKEN`, `TELEGRAM_CHAT`.

Это учебная проверка системы, а не совет покупать.
